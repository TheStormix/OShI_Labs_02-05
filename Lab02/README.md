# Основи штучного інтелекту — лабораторна робота №2

**Варіант №9. Тема:** лінійна регресія та лінійна класифікація.

## Завдання

- Приклади №1, №2 і №13 із лабораторного практикуму.
- Задачі №1 і №5 за параметрами таблиці 3: `a=1`, `b=2`, `c=0`, `d=3`.
- Побудова регресійних моделей і лінійного класифікатора, оцінка якості та візуалізація результатів.

## Структура

- `OShI_Lab02_Variant09.ipynb` — програмний код, пояснення, результати й графіки.
- `requirements.txt` — Python-залежності.
- `results/` — 7 PNG-графіків, які генерує Notebook.

## Методика

Приклади побудовано за матеріалами лабораторного практикуму Копея В. Б. та Ониська О. Р. (2024), с. 5–8, 24–26, 54–56.

- У задачах №1 та №5 використано фіксоване зерно `seed=9` для відтворюваної генерації випадкового шуму.
- У регресійних прикладах значення `R²` обчислюється на навчальних даних, як у методичних вказівках.
- Для задачі №5 окремо виділено тестові дані та обчислено метрики класифікації.

## Відтворення

Notebook виконується в Python-середовищі з `numpy`, `pandas`, `matplotlib`, `scikit-learn` та `notebook`. Файл `OShI_Lab02_Variant09.ipynb` відкривається у Jupyter Notebook; усі комірки виконуються послідовно.
