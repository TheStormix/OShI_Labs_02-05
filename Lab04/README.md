# Основи штучного інтелекту — лабораторна робота №4

**Варіант №9. Тема:** методи кластеризації даних.

## Завдання

- Приклад №19 з методичних вказівок: порівняння алгоритмів кластеризації.
- Задача №8, варіант №9: генерація 20 двовимірних точок, побудова кластерів, оцінювання якості та прогноз для нової точки.
- Параметри генерації: `a=1`, `b=2`, `c=0`, `d=3`, `s=0.5`.

## Алгоритми та оцінювання

- **K-Means** — кластеризація за центрами та прогноз належності нової точки до кластера.
- **AgglomerativeClustering** — ієрархічне об'єднання об'єктів.
- **DBSCAN** — кластеризація за щільністю з можливістю позначення шуму.
- **ARI (Adjusted Rand Index)** — порівняння отриманих кластерів із відомими мітками класів. Мітки не використовуються під час навчання моделей.

## Структура

- `OShI_Lab04_Variant09.ipynb` — програмний код, пояснення, метрики та візуалізації.
- `results/` — 10 PNG-графіків і CSV-таблиці результатів, що створюються Notebook.

## Відтворення

Notebook запускається у Jupyter Notebook з установленими `numpy`, `matplotlib`, `pandas` і `scikit-learn`. Усі комірки виконуються послідовно. Для повторюваності генерації даних використано `seed=9`.
